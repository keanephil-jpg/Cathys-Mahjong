# Cathy's Mahjong

A touch-friendly 144-tile layered Mahjong Solitaire game for iPad and desktop.

## Publish on GitHub Pages
1. Create a new repository.
2. Upload all seven files from this ZIP to the repository root.
3. Open Settings, then Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Select main and /(root), then Save.

## iPad
Open the published game in Safari, use Share, then Add to Home Screen.

Each new deal is constructed from a complete legal removal route, so every starting board has a solution. Different choices can still cause a dead end; Safe hint, Undo and Restart deal are included.
